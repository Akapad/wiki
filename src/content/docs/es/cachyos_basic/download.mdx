## Descargando ISO

CachyOS se puede obtener de las siguientes fuentes:

*   [Web](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Mirror](<https://mirror.cachyos.org/ISO/>)

## Verificando la integridad de la ISO con SHA256

:::caution[PELIGRO]
Verifica siempre la integridad de la ISO antes de la instalación o creación del medio de instalación, esto evitará cualquier error indeseado.
:::

**Versión actual:** `250713`

**Hash SHA256:** `22a1e3386a1a25c433f1b9dd5272062856d8311ee637900c5017df7fa40bf627`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Descarga el [archivo](https://mirror.cachyos.org/ISO/desktop/250713/cachyos-desktop-linux-250713.iso.sha256) que contiene el hash SHA256 **(Ábrelo con un edito de texto e.j: Notepad).**
2. Abre el CMD o PowerShell como Administrador [navega](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) a la ruta donde se ha guardado el archivo SHA256 y el ISO.
3. Ejecuta el siguiente comando:

   ```powershell
   # Ejemplo:
   certUtil -hashfile cachyos-desktop-linux-250713.iso SHA256
   ```
4. Compara la salida del hash certUtil con el archivo descargado en el **paso 1**. Si coinciden, puedes proceder con la instalación de CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Descarga el [archivo](https://mirror.cachyos.org/ISO/desktop/250713/cachyos-desktop-linux-250713.iso.sha256) que contiene el hash SHA256.
2. Abre el terminal y navega hasta el directorio que contiene el archivo `.sha256` y ejecuta el siguiente comando:

   ```sh
   # Ejemplo:
   cd Downloads/
   cat cachyos-desktop-linux-250713.iso.sha256
   # 22a1e3386a1a25c433f1b9dd5272062856d8311ee637900c5017df7fa40bf627
   ```
3. Ejecuta el siguiente comando para comprobar el hash actual del archivo ISO y compara la salida con el **Paso 2**.
   ```sh
   # Ejemplo:
   sha256sum cachyos-desktop-linux-250713.iso
   ```
4. Si los hashes del **Paso 2** y el **Paso 3** coinciden, puedes proceder a la instalación de CachyOS.

</Steps>

</TabItem>

## Verifica la Autenticidad de la imagen ISO (Linux)

Para verificar la autenticidad del archivo ISO debes asegurarte que el archivo has sido lanzado por el equipo oficial de desarrollo de CachyOS:

<Steps>

1. Importa la llave GPG para verificar la autenticidad:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Descarga la ISO y su firma `.sig` , ejecuta el siguiente comando (reemplazando `full_iso_name.iso` con el nombre del ISO descargado):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Si tu obtienes un "**Good signature**" en la salida, el archivo ISO es original:
   ```
   gpg: Signature made Mo 01 Apr 2024 14:13:30 CEST
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Si la salida devuelve un "**Bad signature**" o la ID de la llave no es coincide, no utilices la imagen ISO y asegúrate que la imagen descargada procede de un fuente legitima de CachyOS.
Una mala firma sugiere que la imagen descargada puede haber sido manipulada.
:::
